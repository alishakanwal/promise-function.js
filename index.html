Promises

Q1. Bank Account Withdrawal

let balance = 10000;
let withdrawalAmount = 7000;

let withdrawal = new Promise((resolve, reject) => {

    if (balance >= withdrawalAmount) {
        resolve("Withdrawal Successful!");
    } else {
        reject("Insufficient Balance!");
    }

});

withdrawal
    .then((result) => {
        console.log(result);
        console.log("Remaining Balance:", balance - withdrawalAmount);
    })
    .catch((error) => {
        console.log(error);
    });

Withdrawal successful. Remaining balance: Rs. 3000

Q2. Online Exam Result

let marks = 75;

let result = new Promise(function (resolve, reject) {
    if (marks > 100 || marks < 0) {
        reject("Invalid marks");
    } else if (marks >= 50) {
        resolve("Pass");
    } else {
        resolve("Fail");
    }
});

result
    .then(function (message) {
        console.log(message);
    })
    .catch(function (error) {
        console.log(error);
    });
Pass

Q3. Product Delivery System

let delivered = true;

let delivery = new Promise(function (resolve, reject) {
    setTimeout(function () {
        if (delivered) {
            resolve("Product Delivered Successfully");
        } else {
            reject("Delivery Failed");
        }
    }, 3000);
});

delivery
    .then(function (message) {
        console.log(message);
    })
    .catch(function (error) {
        console.log(error);
    });
Product Delivered Successfully (after 3 seconds)

Q4. Promise Chaining

let numberPromise = new Promise(function (resolve) {
    resolve(10);
});

numberPromise
    .then(function (num) {
        return num + 20;
    })
    .then(function (num) {
        return num * 2;
    })
    .then(function (num) {
        return num - 5;
    })
    .then(function (num) {
        console.log("Final Result: " + num);
    });
Final Result: 55

How to Check the Result

Follow these steps to check the output of the JavaScript programs:

01

Open the JavaScript File

Open the JavaScript file in your code editor and make sure the code is saved.

02

Open the HTML Page

Open the HTML file in Google Chrome or another web browser.

03

Open Developer Tools

Right-click on the webpage and select Inspect.

04

Go to the Console

Click the Console tab in Developer Tools to view the JavaScript output.

05

Check the Output

Run the JavaScript program and check the result displayed in the Console.

Note: If the program uses prompt(), enter the requested value when the popup appears. The result will be displayed in the Console.
